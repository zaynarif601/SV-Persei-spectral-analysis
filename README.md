# High-Resolution Spectroscopy of Classical Cepheids
**M.Sc. Research Project — IUCAA, Pune (2026)**  
Supervisor: Dr. Anupam Bhardwaj, Assistant Professor, IUCAA, Pune

## Overview

Automated Python pipeline for deriving atmospheric parameters and metallicity 
of Classical Cepheids from high-resolution echelle spectra.
Applied to **SV Persei** using CFHT/ESPaDOnS data (R ≈ 80,000).

**Derived parameters:**

- T_eff = 5055 ± 21 K
- log g = 0.66 ± 0.03 dex
- ξ_t   = 2.89 ± 0.12 km/s
- [Fe/H] = −0.107 ± 0.04 dex
